# 🌍 Travel Advisor

A modern Travel Advisor web application that helps users discover nearby restaurants, hotels, tourist places, weather information, and locations using an interactive map.

The application supports current-location detection as well as city-based search.

## 🚀 Project Overview

Travel Advisor is a React-based web application designed to help users explore places around their current location or any searched city.

The application displays nearby:

- Restaurants and Cafes
- Hotels and Guest Houses
- Tourist Attractions
- Weather Information
- Interactive Map Locations

Users can search for cities such as:

- Guntur
- Vijayawada
- Chennai
- Hyderabad
- Bengaluru

and immediately explore nearby places.

---

## ✨ Features

### 📍 Current Location Detection

The application automatically detects the user's current location using the browser Geolocation API.

Users can also return to their current location using the **Use My Location** button.

### 🔎 City Search

Users can search for any city using the search bar.

The application automatically updates:

- Map location
- Weather
- Restaurants
- Hotels
- Place markers
- City name

### 🍽️ Restaurants & Cafes

Displays nearby:

- Restaurants
- Cafes
- Fast-food locations

Information may include:

- Place name
- Cuisine
- Address
- Phone number
- Opening hours
- Website

### 🏨 Hotels

Displays nearby accommodation including:

- Hotels
- Guest houses
- Motels
- Resorts

### 🗺️ Interactive Map

The application uses **Leaflet with OpenStreetMap**.

Features include:

- Zoom in/out
- Map navigation
- Individual location markers
- Place popups
- Automatic map movement after city search

### 🌤️ Weather Information

Weather information is dynamically displayed based on the selected location.

Weather details include:

- Current temperature
- Weather condition
- Feels-like temperature
- Wind speed

### 📌 Dynamic Location Titles

The interface dynamically displays the selected city.

Restaurants & Cafes in Guntur
Hotels in Vijayawada
